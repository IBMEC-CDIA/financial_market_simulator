Implemente exclusivamente a spec SPEC-001.

Antes de começar:
- Leia a especificação integralmente.
- Analise os arquivos relevantes e os padrões arquiteturais existentes.
- Verifique os critérios de aceitação e as dependências.

Durante a implementação:
- Respeite a arquitetura, as convenções e o estilo do projeto.
- Implemente somente o escopo desta spec.
- Evite refatorações não relacionadas.
- Crie ou atualize testes automatizados para os requisitos implementados.
- Não remova funcionalidades existentes nem altere contratos públicos sem necessidade justificada.

Após implementar:
1. Execute os testes relevantes.
2. Execute as verificações de qualidade disponíveis no projeto, como lint, type checking e testes de integração, quando aplicáveis.
3. Corrija os problemas introduzidos pela implementação.
4. Verifique cada critério de aceitação da spec.
5. Apresente um relatório com arquivos alterados, funcionalidades entregues, testes executados, resultados e limitações conhecidas.

Não inicie nenhuma outra spec.

Se houver ambiguidade relevante, dependência ausente ou falha que não possa ser resolvida com segurança, interrompa o trabalho e explique o impedimento.

Considere a spec concluída somente quando seus critérios de aceitação estiverem atendidos e as verificações pertinentes tiverem passado.
